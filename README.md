# Kişisel Panel

Ders programı, sınavlar, ödevler, mezuniyet yolu, eğitimler, hedefler, staj başvuruları, projeler, kitap/film/dizi takibi ve kişisel finans için tek sayfalık panel.

- Aç: `index.html` (çift tıkla) ya da GitHub Pages adresi.
- Veriler: `data.js`. Claude'a sohbette söyle, o güncellesin.
